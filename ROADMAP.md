# Roadmap

- Preserve read-only camera access, lifecycle cancellation and fresh-observation checks.
- Revalidate the adapter when updating the Home Assistant runtime baseline.
- Expand deterministic packaged-install and privacy regression tests.
- Measure coverage across the integration and release tooling before claiming Silver coverage.
- Arrange a backup maintainer and a tested access-recovery process.

These are priorities, not delivery promises or claims of completed qualification.
Completed changes are recorded in [CHANGELOG.md](CHANGELOG.md). Propose priorities
through GitHub issues; release decisions follow [RELEASING.md](RELEASING.md).
